# AIpet 插件目录

放这里的每个**文件夹**都是一个插件，能给她多加一项本事（不改核心代码）。

⚠ 注意：这里说的是 **AIpet 插件**（插件系统）。
项目里其它 `plugins/xxx`（galgame、time_guard 那些）是 **QQ/微信功能模块**，
配置方式完全不同，别混在一起。判断标准很简单：**有 `main.py` 的才是 AIpet 插件**。

## 怎么做一个插件

新建一个文件夹（名字随意，比如 `天气/`），放两个文件：

**`plugin.json`**
```json
{
  "name": "天气",
  "description": "查今天天气",
  "marker": "天气",
  "version": "1.0",
  "author": "你",
  "enabled": true
}
```

**`main.py`**
```python
def rules() -> str:
    # 可选：加进她的提示词，让她知道有这个能力
    return "【天气】你可以查天气，写一行【插件:天气】城市名。"

def handle(arg: str) -> str:
    # 必需：她说【插件:天气】后面的内容会传进来；返回一句结果（她会转述给主人）
    return f"{arg}今天晴，20~28 度。"

def schedule() -> list:
    # 可选：[(间隔秒, 无参函数)]，桌宠会定期调用（最小 30 秒）
    return []
```

## 怎么用

对她（或直接打字）说：**「【插件:天气】北京」**
桌宠会把这个标记留住、交给插件执行，再把结果交给她，她用自己的话讲给你听。
标记那一行**不会念出来**。

## 开关与查看

- 右键菜单 →「电脑与学习」→「启用插件」/「打开插件目录」
- 「她的状态 / 记忆 / 提醒」窗口里能看到装了哪些插件

## 安全

插件跟桌宠**同权限运行**（等于你装的小软件），只放你自己写的或信得过的。
默认关闭的插件：把 `plugin.json` 里的 `enabled` 设成 `false` 即可。
