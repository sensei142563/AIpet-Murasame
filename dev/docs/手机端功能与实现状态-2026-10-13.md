## 六、明确的缺口（诚实清单）
1. **真机回归未做**：`adb devices` 显示无设备；扫码登录 → 文字/图片/表情包收发 → 白名单 → 记忆读写 → 角色切换，这条全链路**没有回归过**。
2. **手部互动的真机验证未做**：要关掉「试手」用真手验，并确认坐标方向与幅度。
3. **包体 302 MB**（已分析、已实删 20.34 MB；**用户指示：先不管包体，先实现功能** ⇒ 暂缓）。
4. **手势不止"捏合"**：目前只做了捏合；握拳/挥手/比心等都可以用同一套关键点扩展（`HandGesture` 是纯函数，加一个判定就能加一个手势 + 一组单测）。

## 七、怎么继续往下走（推荐顺序）
1. 真机回归（要插手机）——这是唯一能把上面 ⏳ 变 ✅ 的事；
2. 手部互动真机调参（只调 `__lookAt` 的 0.45/0.30/1.30 与相机朝向/镜像）；
3. 按需扩展手势（每个手势 = 一个纯函数 + 一组单测，不需要真机就能写）；
4. 包体优化（等用户发话）。
