# 2D→3D 操作手册：下载什么、怎么一步步做出"她的 3D 形象"

> 2026-10-12。回答用户的问题「怎么 2D→3D？我要下载什么软件？」。
> 结论：**用 VRoid Studio**（免费、Windows）做出 `.vrm`，然后交给我一条命令换上去并自动验收。
> 网站类 AI（Meshy/Tripo）能出网格，但**动漫脸会崩、还要自己绑骨**，不适合当最终资产。

---

## 0. 先说清一件事：Live2D 的立绘**不能**"转"成 3D

| | Live2D 立绘（你现在用的） | VRM 3D 模型（要做的） |
|---|---|---|
| 本质 | 一张图切成若干 **2D 网格**，靠变形做伪 3D | **3D 网格 + 骨骼蒙皮** |
| 能不能转换 | ❌ 不可逆 —— 里面没有任何 3D 拓扑信息 | ❌ 无法从 2D 网格"推"出正确拓扑 |

⇒ 所以要**另做一个 3D 的她**（这正是你原话里 D4「双轨模型」：Live2D 是日常形态，VRM/3D 是 AR 形态，**两个都保留**）。

---

## 1. 要下载的软件（只有一个）

### ✅ VRoid Studio（免费，Windows 桌面版）
- 官方下载页：**<https://vroid.com/en/studio>**（日文站：<https://vroid.com/studio>）
- 选 **Windows** 版本下载安装即可；**完全免费**，商用需看它页面的条款（个人玩不受影响）
- 为什么是它：
  - 导出**直接就是 `.vrm`** —— 自带 humanoid 骨骼、表情（happy/angry/blink 等）、spring bone（头发物理）
  - **不需要绑骨、不需要重拓扑**（这是它相对 AI 生成最大的优势）
  - 动漫脸质量可控，做丛雨这种"紫发、和风、刀魂"气质很合适

### ❌ 不推荐作为最终资产的（了解即可）
- **Meshy / Tripo / Rodin / Hunyuan3D** 等"图→3D"网站：几分钟出网格，适合看形体比例；
  但**动漫脸容易崩**（眼睛/五官不稳），网格面数高、拓扑乱，**绑骨与表情要另外做**。
- 所以它们只能"探路"。真要走这条路，链路是：网站出网格 → Blender 绑骨 → 导出 VRM（长得多）。

## 2. 在 VRoid Studio 里的操作（大约 20~40 分钟）

1. 新建角色 → 选一个接近的**预设脸型**
2. **脸**：眼型/瞳色（丛雨是**紫瞳**）、眉、嘴
3. **发型**：选一个长直发/和风发型，**染成紫色系**（可下拉调色）
4. **服装**：和风/巫女/制服类都行；颜色走深紫+白
5. **身体比例**：身高建议贴近 Live2D 的观感（少女体型、头身比别太大）
6. **表情**：至少保留 `Happy` / `Angry` / `Blink`（我的代码会用到"笑/生气/眨眼"）
7. **导出**：右上角 `Export` → 选 **VRM** → 得到 `xxx.vrm`

> 💡 小技巧：先随便捏一个导出（3 分钟），我立刻帮你上机看效果；再回去精修。
> "先能跑起来，再变好看" —— 这样不会卡在捏脸上。

## 3. 导出之后交给我（一条命令）

把 `.vrm` 文件路径发我，我执行：

```bash
python dev/scripts/vrm_swap.py <你的.vrm>
```

它会：
1. **体检**：VRM 1.0 / humanoid 骨骼齐备 / 有表情 / 许可信息 —— 不合格直接拒绝（不浪费你时间）
2. **备份**手机上现有模型（`model.vrm` → `model.vrm.bak`，只备份一次，不覆盖原始备份）
3. **推送**到手机 `files/vrm/model.vrm`
4. **上机验收**：自动进 3D 演示页 → 截图 → **像素判定**（统计画面里不同颜色数，空白画面只有几十个，正常渲染是几千以上）→
   **不合格自动换回旧模型**

⇒ 你只需要在手机上打开 3D 页看一眼："是她 ✓" 或 "不像 ✗"，后者我立刻回滚。

## 5. 常见疑问

**Q：能不能用手机上现成的照片直接生成？**
A：不能直接用。照片→3D 只能走 AI 那条路（脸会崩、要绑骨）。VRoid 是"捏"出来的，质量可控。

**Q：能不能下载别人的 VRM 来改？**
A：可以（VRoid Hub / BOOTH 上有免费 VRM），但**必须看清许可**；换色改性在 VRoid Studio 里就能做。
这条路比从零捏快，但风格不一定贴。

**Q：一定要 Windows 吗？**
A：VRoid Studio 也有 **macOS / iPad / iPhone** 版（iPad 版叫 VRoid Mobile 相关）；本机是 Windows，推荐桌面版。

**Q：做出来的 `.vrm` 放哪？**
A：交给我就行，我负责推进手机并验收。**模型文件不进 git 仓库**（第三方资产不提交，这是既定规矩）。
