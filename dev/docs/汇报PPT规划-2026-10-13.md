## 0. 讲故事的骨架（先定调子，再填内容）

**一句话定位**：
> 市面上的桌宠，要么**只有形象**（Shimeji / Desktop Mate / Live2DViewerEX / 《你妈》），
> 要么**只有对话**（AstrBot / LangBot / chatgpt-on-wechat）。
> 我们做的是**把两边接起来的那一个**：有形象、会说话、记得住你、还能在 QQ 里陪你。

**叙事弧线（四幕）**：
1. **现象**：桌宠这波热度是真的（《你妈》登过 Steam 热搜第一；Desktop Mate 25+ DLC）——但大家玩几天就腻。
2. **为什么腻**：市面桌宠**没有真正的 AI 对话**、**几乎没有长期记忆**、**语音是预录片段而不是生成**。
   （有出处：报道原话"三天后就忘了""新鲜劲过后就觉得不好玩了"）
3. **我们做了什么**：不是重复造桌宠，而是**把"形象 + 语音 + 记忆 + 即时通讯"这四件事打通**，
   并且**关键能力跑在本地**（本地模型、本地记忆、本地语音），不依赖云服务。
4. **接下来**：把"记忆"做成真正的壁垒（跨设备同步、可演进），把 3D/AR 与可互动做深。

**给导师的一句话**（可直接说）：
> "桌宠这个赛道不缺形象，缺的是**记得住人的**桌宠。我们的壁垒不在'画得像'，
> 而在**记忆 + 语音 + IM 打通的整合度**，以及**全链路本地化**。"

### 1.3 "我们有、别人普遍没有"的清单（壁垒页，逐条带证据）

| 我们的能力 | 市面对照（带证据） |
|---|---|
| **长期记忆（本地）** | Open-LLM-VTuber（14k★，最成熟开源 AI 陪伴）README 原文 **"长期记忆功能暂时下线"**；AIRI 的记忆仍是 WIP |
| **生成式语音 TTS + STT 闭环** | 商业桌宠的语音是**预录音频**：Desktop Mate 靠 DLC 配音、anime-desktop-pet 是 133 条 CV，**不是生成** |
| **QQ / 微信打通（且桌宠是本体）** | 接 IM 的项目本体都没形象；有形象的项目都不接 IM（见上） |

| **跨设备** | 全表只有 Live2DViewerEX 有手机端；**没有任何产品支持"手机继承桌面端角色记忆"** |

### 1.4 诚实页（建议保留一页，导师会问）

- 我们**不是首创**：唯一完整对手 super-agent-party 存在 ⇒ 差异化必须落在**整合度 / 开箱体验 / 本地化深度**。
- 不适用的营销话术："全球首个""没人做过"——**不要写**。
- 需要标注为"未查证"的：MaiBot 语音能力、AIRI 是否支持 QQ、Neuro-sama 记忆机制、
  所有 star 数为 shields.io 约数、Steam 不公开销量（只用评测数）。
- 场景风险（校园答辩可能被问）：《你妈》含成熟内容提示、德国 IGRS 评为 BANNED；
  报道有"孩子说不想写作业 → AI 答那就不写啦"的不良引导 ⇒ **我们不做这类内容**。

## 2. 第二块：功能展示 + 实现方法

### 2.1 展示页（每页一个"能看见"的功能，配截图/录屏）

| 页 | 功能 | 展示什么 | 实现方法（一句话 + 技术名词） |
|---|---|---|---|
| F1 | **桌宠本体** | 桌面上的丛雨：拖拽、换装、动作、装饰 | PyQt5 透明置顶窗口 + Live2D Cubism 渲染；服装/动作/装饰图层按角色包配置 |
| F2 | **会说话** | 对话 + 语音朗读 | 对话：LLM（DeepSeek/千问）；朗读：**电脑端 F5-TTS 本地服务**（127.0.0.1:9881）+ 系统 TTS 兜底 |
| F3 | **记得住** | 记忆页 / 她学到的东西 | 分层记忆（短期对话 + 长期归纳）+ 自主学习（空闲自习、写日记）+ **离线可测的导入导出**（`aipet.memory/1` 协议，多重集合并、幂等） |
| F4 | **QQ 里也能聊** | QQ 面板：会话列表、收消息、回消息、发表情包 | OneBot 11 协议（NapCat）+ 自研桥接；**表情包由本地模型 NanoJev 决策**（0.6B，本地 CUDA） |
| F5 | **手机会陪她**（安卓） | 手机 App：聊天页 / 记忆互通 / AR | Kotlin + Compose；Live2D 用 Cubism Native；AR = CameraX + 透明叠加 |

| F7 | **3D 形象（进行中）** | 3D 演示页 + 3D AR（她站在真实地板上） | WebView + three.js + `@pixiv/three-vrm`；相机 FOV 与真实相机对齐（70.9°）；**像素级验收**（画面中段 25287 种颜色） |
| F8 | **工程化（加分项）** | 一键验收报告：22 项真机检查 | Gradle → adb → uiautomator → 断言；离线回归闸门 `verify_all.py` |

### 2.2 实现方法页（建议 2~3 页，"讲得清"比"画得花"重要）

- **架构一页图**：桌宠本体（PyQt5）／对话与记忆（Python）／QQ 桥（OneBot11）／手机端（Kotlin）／本地模型（F5-TTS、NanoJev、STT）。
- **"本地优先"设计**：哪些跑本地（记忆、TTS、表情包决策、STT）、哪些可选云端（对话模型），以及为什么。
- **工程方法（很适合高校汇报）**：三条纪律 ——
  1. **判据必须来自不会说谎的通道**（截图/像素/日志，而不是"应该没问题"）；
  2. **每个"未验证"都如实标注**（我们把这条写进了文档）；
  3. **一键可复现**（`verify_all.py` 离线闸门 + 真机验收脚本）。

## 3. 第三块：未来规划

| 阶段 | 做什么 | 为什么（对应市场空白） |
|---|---|---|
| 近 | **记忆做成壁垒**：跨设备同步（手机继承电脑记忆）、记忆可视化与可编辑 | 全市场**没人做跨设备记忆** |
| 近 | **语音闭环打磨**：STT 准确率量化、打断（barge-in）、情感语调 | 商业桌宠语音是预录，非生成 |
| 中 | **可互动**：手部/姿态感知 → 她看向你的手、对动作有反应（端侧视觉，只发结构化结果） | 主动性/不可预测性普遍不足 |
| 中 | **3D 形象落地**：换成"她"的 VRM（建模路线见 `dev/docs/2D转3D-操作手册-下载什么软件.md`） | 3D 桌宠（Desktop Mate/MateEngine）价格 ¥26~76/DLC，我们可免费换装 |
| 远 | **安卓端自足**（不依赖 Termux 的 QQ 通道） | 装机门槛是产品化最大障碍 |
| 远 | **科研结合**：毫米波/视觉动捕用于"看懂人的状态"（如久坐提醒、情绪陪伴） | 与实验室课题方向对齐（帕金森动作识别那套的迁移） |
