## 2. 录屏清单（5 段，每段 30~60 秒）

> 每段开录后**先停 1 秒再动手**（剪辑省事）；说完话**再停 1 秒**结束。

### C1 · 她活着（约 30s）
1. 双击 `启动桌宠.bat`，让控制台自己滚起来（**别关控制台**，它是"她启动的证据"）；
2. 等窗口出现、立绘站好；
3. 鼠标在她身上晃一下、点一下（她会看着你 / 有反应）；
4. 结束。
**这段讲**：这是一只有形象、能对话、能自己在桌面上待着的桌宠。

### C2 · 换装是立即生效的（约 40s）
1. 右键 → 换装与立绘 → 依次点 **制服 → 睡衣 → 私服 → 刀服**；
2. 每换一件停 2 秒让人看清确实变了；
3. 结束。
**这段讲**：换装不是重启才生效，是**点了就变**（本轮刚修完并加了回归测试）。

### C3 · 她会聊天、会记事（约 60s）
1. 点她 → 输入「我最近在准备一个汇报，有点紧张」；
2. 等她回完；
3. 右键 → 她的状态 / 记忆 / 提醒 → 切到「记忆」页，把刚才那句被记下来的内容露出来；
4. 结束。
**这段讲**：她不是一次性问答，**会攒长期记忆**，下次聊天会自己用上。

### C4 · 她能操作电脑（约 40s，**这段是加分项，有把握再录**）
1. 右键 → 电脑与学习 → 打开「允许操控电脑（键鼠）」；
2. 对她说一句明确的小任务（例如「打开记事本」）；
3. 让画面自己跑完（会出现"正在操作电脑……"，然后她汇报做了什么）；
4. 结束。
**这段讲**：她能真操作本机 —— 这也是与"只会卖萌的桌宠"的最大差异点之一。

### C5 · 一键验收 / 自检（约 40s）
1. 在终端跑 `runtime\venv\Scripts\python.exe tests\run_all.py`；
2. 让它滚到最后的 `总计 … 0 个文件失败`；
3. 结束。
**这段讲**：381 项自检全绿 —— 这不是"我这儿能跑"，是**有回归门禁**的工程。
