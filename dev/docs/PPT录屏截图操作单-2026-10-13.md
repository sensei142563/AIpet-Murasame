## 2. 录屏清单（5 段，每段 30~60 秒）

> 每段开录后**先停 1 秒再动手**（剪辑省事）；说完话**再停 1 秒**结束。

### C1 · 她活着（约 30s）
1. 双击 `启动桌宠.bat`，让控制台自己滚起来（**别关控制台**，它是"她启动的证据"）；
2. 等窗口出现、立绘站好；
3. 鼠标在她身上晃一下、点一下（她会看着你 / 有反应）；
4. 结束。
**这段讲**：这是一只有形象、能对话、能自己在桌面上待着的桌宠。

### C2 · 换装是立即生效的（约 40s）
1. 右键 → 换装与立绘 → 依次点 **制服 → 睡衣 → 私服 → 刀服**；
2. 每换一件停 2 秒让人看清确实变了；
3. 结束。
**这段讲**：换装不是重启才生效，是**点了就变**（本轮刚修完并加了回归测试）。

### C3 · 她会聊天、会记事（约 60s）
1. 点她 → 输入「我最近在准备一个汇报，有点紧张」；
2. 等她回完；
3. 右键 → 她的状态 / 记忆 / 提醒 → 切到「记忆」页，把刚才那句被记下来的内容露出来；
4. 结束。
**这段讲**：她不是一次性问答，**会攒长期记忆**，下次聊天会自己用上。

### C4 · 她能操作电脑（约 40s，**这段是加分项，有把握再录**）
1. 右键 → 电脑与学习 → 打开「允许操控电脑（键鼠）」；
2. 对她说一句明确的小任务（例如「打开记事本」）；
3. 让画面自己跑完（会出现"正在操作电脑……"，然后她汇报做了什么）；
4. 结束。
**这段讲**：她能真操作本机 —— 这也是与"只会卖萌的桌宠"的最大差异点之一。

### C5 · 一键验收 / 自检（约 40s）
1. 在终端跑 `runtime\venv\Scripts\python.exe tests\run_all.py`；
2. 让它滚到最后的 `总计 … 0 个文件失败`；
3. 结束。
**这段讲**：386 项自检全绿 —— 这不是"我这儿能跑"，是**有回归门禁**的工程。

**C6 的注意事项（重要）**
1. 必须**先把「试手」关掉**——否则录到的是假手在动，一眼就会被看出来；
2. 若视线方向反了或幅度怪：**只调 `assets/vrm/index.html` 里 `__lookAt` 的两个系数
   （0.45 / 0.30）与 1.30 的高度基准**，不要去改检测器和坐标换算
   （那两层已被单测与 `HandTouch` 的约定固定住）；
3. 捏合的触发日志是 `捏合触发 ratio=…`，挥手是 `挥手触发（横向归一化=…）`，
   握拳是 `握拳触发 ratio=…` —— **录的时候可以让日志一并入镜**，这比空口说有说服力；
4. 手机与电脑要在同一网络下，chatter 要先能看到电脑（`NetDiag` / `NetEnv` 那套）。

### C7 · 换一套衣服，QQ 里立刻也是这一套（约 40s，**第 15 页的现场证据**）

**为什么要这一段**：deck 第 15 页写着「QQ 侧立绘与桌宠同一套装扮」。
这句话目前只做过**代码级**验证（两侧读同一个 `data/portrait_choice.json`、
走同一个 `tool/portrait_outfit` 模块，因此含丛雨的 `pets.<id>.<set>` 布局都成立）——
**没有**拍过"两张图确实是同一套"。这段录屏就是补上它。

**怎么录**
1. 桌宠在桌面上，右键 → **换装与立绘** → 换一件明显不同的衣服（例如 刀服 → 制服）；
2. 立刻截图或让画面停一下，能看清桌面立绘换了；
3. 在 QQ 里 @ 她、让她发一张立绘（触发词见 `qq/qq_chat.py` 的 `[立绘:情绪]` 标记；
   简单办法是说一句带情绪的话，例如"今天好开心呀"）；
4. **把 QQ 里那张立绘和桌面立绘并排入镜**，让"同一套衣服"一眼看得出来。

**这段讲**：她不是"两个形象"——桌面和 QQ 里是**同一个人、同一套装扮**，
换装写的是**共享配置**，所以两边同时生效、并且记住到下次启动。

**注意**
- 换装后如果 QQ 那边的形象没立刻变，**先确认换的是"当前显示那套"**（`a` / `b` 是两套独立配置）；
- 若两张确实不一致，**那就是真 bug**：请把两张图都发我，我按
  `dev/docs/验证-QQ立绘与桌宠同一套装扮-2026-10-13.md` 里的链路逐段回查。
