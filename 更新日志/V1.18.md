# V1.18 — 融合另一条开发线：她的"内心"九个模块 + 状态窗 + 插件框架 + 联网搜索


这一版把**另一条开发线**（远端被强推替换的那条）里真正自包含、真有用的东西，按本仓库的架构重新实现了一遍。原则：**以本仓库为基座**，不收对方整文件，只收"能力 + 真 bug 修复"，每一样都有离线探针验证过。

- **💗 她的"内心"九个模块**（这次的主体，都是"她会自己变化"的东西）：
  - `tool/state.py` **心情与好感度**：随互动升降、随时间回落（离线也补算），注入对话提示词
  - `tool/habits.py` **主人的习惯**：作息 / 活跃时段 / 常用软件（只记计数与时段，不记内容）
  - `tool/attention.py` **开口时机打分**：该不该在这时候说话（硬闸门 + 六类加减分，防话痨）
  - `tool/desire.py` **动机层**：无聊 / 想说话 / 精力随时间变化 + 活跃度档位（安静·适中·活跃）
  - `tool/care.py` **主动关怀**：熬夜催睡、久坐提醒、"在一起第 N 天"、开机问候
  - `tool/reminder.py` **提醒 / 待办 / 番茄钟**：你交代的事**一定**会叫你（只让勿扰挡）
  - `tool/experience.py` **任务经验**：她做过的事记下来，下次先查经验再交给 agent
  - `tool/autonomy.py` **自主行动分档**：只读可自主 / 改动要你开口 / 危险永不做
  - `tool/self_learn.py` **自主学习**：四层记忆（工作·情节·语义·画像）+ 自习 + 日记 + 夜间整理
- **🪟 「她的状态」一页看完**（右键菜单）：5 个标签页把上面九项摊开，坏了的项**标红写出原因**（不是静默留空）；带「复制全部 / 打开数据目录」
- **💗 启动器新增「状态」页**（左栏「桌宠」和「记忆」之间）：顶部**一眼列出这次新增的所有开关**（插件系统 / 联网搜索 / 自主学习 / 主动关怀 / 提醒 / 习惯采集 / 开口时机 / 自主行动分档 / 识图模型，标 ✅开 ⭕关 并注明去哪儿改），下面五个标签页把九个内心模块摊开 —— 和桌宠右键「🪟 她的状态」是同一份数据
- **🔌 插件框架**：`plugins/<名字>/{plugin.json,main.py}`，她写一行「【插件:系统信息】」就能用你装的本事；右键「🔌 插件」开关 + 清单（**没加载起来的会写明原因**）
- **🔎 联网搜索**：问「最新 / 今天 / 多少钱 / 是谁」这类事，她**先上网查一眼**再回答，结果带来源网址；搜不到就如实说没查到
- **🖥 性能与抓屏**：全屏游戏时只降进程优先级（**不暂停**识别与搭话）；后台线程改用 Win32 抓屏，修掉"桌宠凭空消失"；中文路径下的 PyInstaller+PyQt5 修复
- **👀 识图改回纯云端并做扎实**：新增 `python -m tool.vision_check` 一条命令看出断在哪一环；修掉「没配 Key 时把人话提示当成屏幕内容喂给她」；主界面截图任务不再用 Qt 抓屏（后台线程会崩）
- **🩺 一键自检** `python -m tool.selftest`：模块 / 接线（95 处）/ 运行时 / 依赖四类，能真抓住断线
- **🧭 前端入口补齐**：启动器左栏新增「💗 状态」页；修掉启动器插件页里**唯一真能用的插件反而不显示**（清单没 `id` 就被整条跳过）；插件页现在会标明哪些条目是"开关面板"（她不能自己喊它，功能在 QQ / 桌宠那边）
- **🔧 配置路径中央化**：`get_config("./config.json")` 这 50+ 处以前依赖"当前目录正好是程序目录"—— 被别的宿主/计划任务/`python -c` 拉起时会**静默退回示例默认值**（"我配好了却不生效"）。现在 `tool/config.py::resolve_path` 统一钉到真正那份配置，写配置一律走 `set_key`（只改一个键 + 原子替换 + 不再静默失败）

> 说明：这一版**不包含**本地视觉模型（要另下 4.43GB 模型、独占约 6GB 显存，与语音合成抢显卡）—— 识图只走云端。远端那条线的 galgame 素材标注工具也没有移植（它们依赖一个远端也不存在的 `story/` 包）。
