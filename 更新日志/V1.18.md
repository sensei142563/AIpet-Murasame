# V1.18 — 融合另一条开发线：她的"内心"九个模块 + 状态窗 + 插件框架 + 联网搜索

> 这一版做的是**融合**：远端 `main` 在 2026-09-25 被强推替换成另一条开发线（本地历史与它没有
> 共同祖先）。我们**以本仓库为基座**，只从那条线里挑"自包含、真有用"的东西，按本仓库架构
> 重新实现，不用对方整文件；每一样都配了离线探针，`python -m tool.selftest` 一项项验过。

## 这一版新增了什么（明天可以照着试）

### 1. 她的"内心"九个模块

| 模块 | 你会看到什么 | 代码位置 |
|---|---|---|
| 心情与好感度 | 摸头/戳她/聊天会让心情与好感度变化，久了会回落；她的话里能感觉到 | `tool/state.py` |
| 主人的习惯 | 她慢慢知道你几点在电脑前、常用哪几个软件（只记计数与时段，不记内容） | `tool/habits.py` |
| 开口时机 | 她不再一有动静就搭话；沉默太久 / 你刚忙完 / 全屏游戏时权重不同 | `tool/attention.py` |
| 动机层 | 无聊 / 想说话 / 精力随时间涨落；安静·适中·活跃三档 | `tool/desire.py` |
| 主动关怀 | 熬夜催你睡、久坐提醒、在一起第 N 天、开机问候 | `tool/care.py` |
| 提醒 / 待办 / 番茄钟 | 你交代的事**一定**会叫你（只让勿扰模式挡） | `tool/reminder.py` |
| 任务经验 | 交给 agent 做过的活会记下来，下次先查经验 | `tool/experience.py` |
| 自主行动分档 | 只读的她可以自己来；改动类要你开口；危险的永不做 | `tool/autonomy.py` |
| 自主学习 | 四层记忆（工作·情节·语义·画像）+ 自习 + 日记 + 夜间整理 | `tool/self_learn.py` |

### 2. 「她的状态」窗口（右键菜单 → 🪟 她的状态）

一页五个标签页：现在 / 习惯 / 心里 / 提醒 / 记忆。
某一段取不到时会**标红并写出原因**（比如"读盘坏了（RuntimeError: ...）"），不会静默留空。
带「刷新 / 复制全部 / 打开数据目录」——出问题时把"复制全部"的内容发我就能定位。

### 3. 插件（右键菜单 → 🔌 插件）

`plugins/<名字>/` 放 `plugin.json` + `main.py` 就能给她加本事；她写一行「【插件:系统信息】」触发。
现在 `plugins/` 里有 10 个目录，**只有「系统信息」是可用的**：
- `_模板例子` 是模板（`enabled: false`，故意关着）
- 另外 8 个（人脸识别 / Galgame / 活泼模式 / 点歌 / 网络用语 / 时间同步 / 空闲离线 / 自主学习）
  **只有 plugin.json、缺 main.py** —— 那些功能本来就没进过本仓库，清单里会如实写明

命令行体检：`python -m tool.plugins`

### 4. 联网搜索（右键菜单 → 🔎 联网搜索）

问她「最新 / 今天 / 多少钱 / 是谁」这类事，她会先上网查一眼再回答，结果带来源网址；
搜不到会如实说没查到。只读搜索、结果缓存 5 分钟、两次至少隔 3 秒。
体检：`python -m tool.vision_check`（识图）/ `python -m tool.web_search`（搜索，默认不联网）

### 5. 顺手修掉的真 bug

- **后台线程里用 Qt 抓屏会让桌宠凭空消失**：（主界面截图按钮那条路也中招了，`ScreenWorker` 之前已修）
  现在统一走 Win32 抓屏
- **识图把人话错误当屏幕内容**：没配视觉模型 Key 时，以前返回"（未配置视觉模型 API Key）"这句
  话，而调用方把它当成"我亲眼所见"塞进提示词 → 她会一本正经地评论这句话。现在任何失败分支
  都返回空串、原因只打印
- **写配置不再整份 dump**：新增 `tool/config.py::set_key`（只改一个键、原子替换、绝对路径），
  避免把示例配置里的占位值（`sk-your-deepseek-key`）当成你的设置落盘
- **性能守卫**：全屏游戏时只降进程优先级，**不暂停**识别与主动搭话（你要的）

## 这一版**没有**做什么（先说清，免得你去找）

- **本地视觉模型**：不跑（要另下 4.43GB 模型、独占约 6GB 显存，还要和语音合成抢显卡）。
  识图**只走云端**（`vision_model_name` + 对应 APIKEY + 本机 `api.py` 代理）
- **galgame 素材标注工具**（`cg_*` / `jp_names` / `se_names`）：那 7 个 `cg_*` 依赖一个
  `story/` 包，而这个包**在远端分支里也不存在**（要跑得我自己新造一套素材索引）。
  素材可以就地读，但**不进仓库**（5GB+）
- 手写的 Windows 自动化（`pc_control` / `uia` / `msaa` / `pc_task` / `music`）：
  已改用 **agent 桥接**（`tool/agent_bridge.py`，DSH 优先、Codex 回落，默认关 + 每次问你）
