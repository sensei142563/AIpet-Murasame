# V1.17.2 — 界面"看不清字"整族修复 + Live2D 画布频闪/崩溃根治


- **🎨 浅色主题下"看不清字"整族修复**：立绘工坊标题（对比度 **1.08:1 → 9.74:1**）、触摸区域调节、角色向导 11 处说明、状态/警告字、Live2D 预览窗口底部按钮、禁用按钮……这些地方以前把老深色界面的颜色（`#e8e8f0` / `#9a9aa8` / `#888` / `#8fd18f` / `#e07a90`）写死在代码里，换成浅色主题（经典 / 千恋万花）就成了"浅字压浅底"。现在一律按当前主题底板算对比度（`colors.readable_on / ok_text / warn_text`），自选「启动器底色」时也跟着对
- **🖼 深色主题下"卡片发白"修复**：插件页 / 桌宠页 / 设置页 / 主题页里写死的"磨砂白"（`rgba(255,255,255,120~190)`）在 Silicon 深色主题下会盖成浅灰板，配主题浅字只有 **1.2~2.1:1**（几乎看不见，实测插件页 26 处不达标 → 3 处）。改成跟主题走的 `surface_fill()`；另外"整页透明化"以前会把实心强调色按钮压成"淡底白字"（选中胶囊 1.70:1），现在这类按钮保持不透明
- **🎭 Live2D 画布"频闪 / 预览窗口崩坏"根治**：Cubism 原生引擎是**进程级单例**，而启动器里最多同时有三个 Live2D 画布（立绘工坊内嵌预览、实时预览窗口、动作/表情调试器），各自建了自己的 GL 上下文 → 第 2、3 个画布画不出模型（实测帧缓冲里"模型墨迹 0.0%"，看着就是闪 / 黑 / 崩）。入口在创建 QApplication **之前**打开 Qt 的共享 GL 上下文后，三个画布同时正常；「实时预览窗口」与「调试器」也不再互相关闭，可同时开着对比
- **🧠 Live2D 表情/动作交给 AI 自己挑**：把该角色可用的表情/动作词表随提示词给 AI，回复里直接选（优先顺序：句内情绪标签 > AI 选择 > 语音情绪兜底）；2D 模式仍按图层 ID 处理，两种模式互不干扰
- **🀄 句内情绪标签支持全角【】**：人设里写的是全角 `【白】`，而代码只认半角 `[白]` —— 诺瓦的"白形态"这条唯一由人设驱动的表情路径**从 v1.12.1 起就没触发过**（现在全角/半角都认，四角色素材零缺失）
- **🐾 槽位面板与徽章**：桌宠槽永远显示当前生效角色（拖出去 = 回到默认角色）；QQ / 微信槽留空 = 跟桌宠一样；三个槽的徽章统一跟随主题强调色
- **🤖 模型名对齐当前主线**：DeepSeek 统一用 `deepseek-flash`（**对话与看图是同一个模型**），设置页下拉与配置默认值同步更新
