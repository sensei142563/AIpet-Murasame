## 三、共性功能总结（市面桌宠普遍都有的）

1. **桌面常驻的透明/无边框置顶窗口 + 拖拽** —— 从 Shimeji、Ukagaka 到 Desktop Mate、MateEngine、《你妈》，无一例外。
2. **鼠标交互反馈** —— 目光/头部跟随鼠标（《你妈》、MateEngine、anime-desktop-pet 16 向视线）、摸头/戳身反馈（Desktop Mate、MateEngine、VPet）、被拖拽（几乎全部）、点击播放语音（Desktop Mate、anime-desktop-pet）。
3. **"坐在窗口/屏幕边缘上"的物理感** —— Shimeji 沿窗口边缘攀爬、Desktop Mate 角色坐在窗口上并在窗口间跳跃、MateEngine 拖到窗口/任务栏上休息。
4. **角色外观可替换** —— Shimeji 图片集、Ukagaka 的 Shell/Freeshell 生态、VPet 创意工坊动画、Live2DViewerEX 的 LPK/Json 导入、MateEngine 的 VRM 导入、Desktop Mate 的角色 DLC。
5. **靠社区/创意工坊维持长尾** —— VPet（创意工坊+代码插件）、Live2DViewerEX（创意工坊）、Wallpaper Engine（>100 万壁纸）、Desktop Mate（持续出 DLC）、Ukagaka（Ghost 生态 + 同人活动）。
6. **效率/陪伴型附加功能** —— 番茄钟与待办：《你妈》、anime-desktop-pet、VPet；时钟/日历/提醒小组件：Live2DViewerEX、Desktop Mate（闹钟）；音乐播放器：《你妈》、Live2DViewerEX、anime-desktop-pet。
7. **平台以 Windows 为绝对主战场** —— 表 1、表 2 中，真正原生跨平台的只有 Live2DViewerEX（含手机端）、Open-LLM-VTuber、uDesktopMascot（Win+mac）和 Desktop Mate（Win+mac）。

## 四、普遍缺失 / 薄弱的功能（差异化机会）

1. **真正的 AI 对话，主流商业桌宠基本缺席。**
   Desktop Mate、Live2DViewerEX、《你妈》、Wallpaper Engine、Shimeji 的官方描述中**均未提及 LLM 对话**；MateEngine 只有"small, local AI with simple messages"；VPet 本体只有 ChatGPT 设置窗口，完整能力靠第三方插件（VPetLLM，仅 11★）。有真正 LLM 对话的集中在开源侧：uDesktopMascot、Open-LLM-VTuber、anime-desktop-pet。
   来源：[Desktop Mate](https://store.steampowered.com/api/appdetails?appids=3301060&l=schinese)、[Live2DViewerEX](https://store.steampowered.com/api/appdetails?appids=616720&l=schinese)、[MateEngine](https://store.steampowered.com/api/appdetails?appids=3625270&l=schinese)、[VPet README](https://github.com/LorisYounger/VPet)、[VPetLLM](https://github.com/ycxom/VPetLLM)

2. **长期记忆几乎空白——这是最明显的一块短板。**
   - Open-LLM-VTuber（14k★，最成熟的 AI 陪伴开源项目）README 原文写着 **"the long-term memory feature is temporarily removed (coming back soon)"**，只能靠聊天记录持久化。
   - 中文开源项目 anime-desktop-pet 用"长期记忆手账 + 对话自动提取便签"来补，是目前少见的正面案例（但只有 9★）。
   - 行业侧佐证：《北京晚报》调查指出，有用户训练 AI 宠物记住钥匙位置，**"三天后宠物就忘了，不具备间隔太久的上下文记忆"**；也有宠物突然"我全不记得了，请你再说一次"导致用户情感崩塌的案例。
   ⚠️ 注意：该报道主要针对**实体 AI 宠物玩具**（毛绒、可换皮肤、带震动/体温），仅部分段落涉及桌宠（"小方块桌宠"），引用时需标注口径。
   来源：[Open-LLM-VTuber README](https://github.com/Open-LLM-VTuber/Open-LLM-VTuber)、[anime-desktop-pet](https://github.com/SherlockYzz/anime-desktop-pet)、[《AI宠物热背后的情感陷阱》](https://finance.sina.com.cn/jjxw/2025-08-20/doc-infmrhsi5343318.shtml)

3. **语音交互（TTS/STT）薄弱且割裂。**
   商业桌宠的"语音"基本是**预录音频片段**（Desktop Mate 的 DLC 角色配音、anime-desktop-pet 的 133 条 CV 原声），**不是生成式 TTS**，无法对任意文本发声。真正的 ASR+TTS 闭环只出现在 AI 取向项目：uDesktopMascot（Vosk STT + COEIROINK 语音）、Open-LLM-VTuber（全栈 ASR/LLM/TTS）、VPetLLM 插件。行业报道亦指出 AI 宠物"**无法识别主人的声音，听谁都是主人**"、反应慢、突然"断片"。
   来源：同上 + [uDesktopMascot README](https://github.com/MidraLab/uDesktopMascot)

4. **主动性与不可预测性不足，留不住用户。**
   报道中原话："消费者普遍反映，**AI 宠物主动性不强，往往新鲜劲过后，就觉得不好玩了**"；用户评价"AI 宠物更像一个'听话'的玩伴，缺少主动性和不可预测性"。目前只有 Open-LLM-VTuber 明确列出 "AI proactive speaking（AI 主动说话）"。
   来源：[《AI宠物热背后的情感陷阱》](https://finance.sina.com.cn/jjxw/2025-08-20/doc-infmrhsi5343318.shtml)、[Open-LLM-VTuber README](https://github.com/Open-LLM-VTuber/Open-LLM-VTuber)

5. **手机端 / 跨设备几乎空白，跨设备"记忆同步"完全没人做。**
   全表中只有 **Live2DViewerEX** 提供 Android/iOS 客户端，**Wallpaper Engine** 有 Android 伴侣 App（但只用于搬运壁纸，非独立桌宠）。**没有任何一款产品支持"手机端继承桌面端角色记忆"**（Steam 云同步的是设置/存档，不涉及角色人格记忆）。
   来源：[Live2DViewerEX](https://store.steampowered.com/api/appdetails?appids=616720&l=schinese)、[Wallpaper Engine](https://store.steampowered.com/api/appdetails?appids=431960&l=schinese)

6. **内容安全与年龄分级是校园/高校场景的真实风险点。**
   《你妈》的 Steam 内容描述符包含成熟内容提示（Revealing outfits and partial nudity），德国 IGRS 直接给了 BANNED；报道中还有"孩子说不想写作业，AI 宠物回答'那咱们就不写啦'"的不良引导案例。若做高校汇报演示，需注意素材筛选与内容分级说明。
   来源：Steam API（appids=4147820）、[《AI宠物热背后的情感陷阱》](https://finance.sina.com.cn/jjxw/2025-08-20/doc-infmrhsi5343318.shtml)

7. **系统兼容与"反作弊"冲突是工程坑。**
   MateEngine 明确因担心触发游戏反作弊，**已禁用"坐在任务栏/窗口上"功能**；Shimeji 需 Java、SSP 需 Windows/Wine 或虚拟机，都是落地时的实际障碍。
   来源：[MateEngine](https://store.steampowered.com/api/appdetails?appids=3625270&l=schinese)、[Shimeji-ee 官网](https://kilkakon.com/shimeji/)、[SSP 官网](https://ssp.shillest.net/)

8. **商业模式的割裂：要么免费无人维护，要么角色单价偏高。**
   开源侧 star 分布极不均衡（Open-LLM-VTuber 14k★ vs anime-desktop-pet 9★）；商业侧 Desktop Mate 走"免费本体 + **¥76/角色 DLC**"路线（Steam API 列出 25 个 DLC），与免费开源的 VPet（43,410 篇评测/98%）形成鲜明对比。用户对"续费才有长期记忆"的模式反感（报道称"这种设定是'有条件陪伴'"）。
   来源：[Desktop Mate DLC 页](https://store.steampowered.com/dlc/3301060/)、[《AI宠物热背后的情感陷阱》](https://finance.sina.com.cn/jjxw/2025-08-20/doc-infmrhsi5343318.shtml)

9. **隐私/离线能力不均。** 云端 LLM 方案（anime-desktop-pet 的云端模型、VPetLLM）需要联网与 API Key；能完全离线跑的是 Open-LLM-VTuber（Ollama/本地模型）、uDesktopMascot（GGUF + Vosk）、anime-desktop-pet 的 Ollama 模式。报道也提示"必须严格筑牢用户隐私数据安全防线"。
   来源：各项目 README + [《AI宠物热背后的情感陷阱》](https://finance.sina.com.cn/jjxw/2025-08-20/doc-infmrhsi5343318.shtml)

## 六、可直接用于 PPT 的三条核心结论

1. **市场已分化为两条路线**：一条是"陪伴/外观向"（Shimeji → Ukagaka → VPet → Desktop Mate → MateEngine →《你妈》），交互做得成熟但**基本没有 AI**；另一条是"AI 向"（uDesktopMascot → Open-LLM-VTuber → anime-desktop-pet），有 LLM/语音，但**长期记忆、跨平台、产品化都还很粗糙**。二者尚未被同一款产品赢家通吃。

2. **AI 桌宠最大的空白是"记忆"与"语音闭环"**：最成熟的开源 AI 陪伴项目 Open-LLM-VTuber 明确移除了长期记忆；商业桌宠用预录语音冒充"会说话"；行业调查指出用户因"三天就忘""听谁都是主人"而流失。**"可长期演进的记忆 + 真正的 TTS/STT 闭环"是当前最清晰的差异化点。**

3. **国内高校/校园场景要注意两点**：一是部分热门桌宠（如《你妈》）带有成熟内容分级与"整蛊梗"属性，Demo 素材需筛选；二是头部商业产品的关键 DLC 存在**区域限制**（Desktop Mate 初音未来 DLC 国区不可用），选型时不能假设"Steam 上有就能用"。
