## 一、语音："说话不像人"（服务方向 7 · **已搁置 D6，存档备查**）

### 1.1 结论（最重要的一条）

> **「不像人」约 55–65% 的听感损失不在声学模型，而在文本层与轮次层。**
> 先改文本与停顿，再谈换模型。**在没做文本层和副语言层之前就去换 TTS，是最常见的边际收益误判。**

### 1.2 根因 → 措施 → 指标

| 子问题 | 可测指标 | 低成本手段 |
| --- | --- | --- |
| **韵律**（语调/重音/节奏/停顿/语速） | F0 曲线均值方差与斜率、音节时长变异系数（nPVI）、停顿时长分布 | 标点→韵律规则表；instruct 情绪字段；轻量韵律预测小模型 |
| **副语言**（呼吸/叹气/轻笑/迟疑） | 每 8–15 秒 ≥1 次吸气事件；每 100 字填充词 1–4 个 | 静音段事件拼贴（0 成本）；标签驱动合成 |
| **音质**（"太干净"） | 底噪 dBFS、混响 T60、4–8kHz 能量比 | **主动加 −40dBFS 底噪 + 0.2s 短混响**，关掉过强 de-esser |
| **内容**（台词太书面） | 平均句长、书面连接词占比、口语标记密度、残句比例 | LLM 口语化改写（**最便宜、见效最快**） |
| **轮次**（不懂打断） | 首音频出包延迟 TTFA、话轮间静音时长、重叠率 | 语义 VAD/预测式端点；全双工模型 |
| **个体一致性** | 跨情绪说话人相似度 SIM 方差 | 音色与情绪解耦；缓存音色 prompt 复用 |

**关键量化认知**（[SpokenTOD/SpokenUS 报告](https://ar5iv.labs.arxiv.org/html/2603.16783)，**[核]**）：
其用户模拟器 Human MOS **4.06**，反而高于真人录音的 **3.67**（8kHz 电话信道）；说话人相似度 0.93 也更"像"。
→ **过度一致的语音反而不像人。**

**全双工路线**：MiniCPM-o 4.5（9B，约 11GB 显存，可离线）、Qwen3-Omni（30B-A3B）、GPT Realtime / Azure Voice Live（有 `interrupt_response`）、vLLM-Omni Realtime Duplex API。
**可直接借用的技巧**：turn-taking 三分类头（`listen` / `barge-in` / `turn-end`），**最后 6 个 token ≈ 240ms @25Hz** 对应人类平均接管反应时间。哪怕不做全双工，这个"越近权重越大"的假警报抑制也适用于 VAD。

### 1.6 三层情绪对齐（文本 → 语音 → 表情/动作）

```
EmotionState = { label, intensity:1..5, arousal:0..1, valence:-1..1, decay_s:5..30 }
```
- 文本层：LLM 输出结构化 `EmotionState`（不要裸文本）
- 语音层：`intensity≤2` 用 instruct 软描述；`≥4` 才换参考音频/风格标签；arousal→语速与 F0 跨度；valence→F0 基线与嘴角
- 表情层：label→`exp3.json`；intensity→参数幅度；arousal→动作频率；decay_s→衰减计时器

> **关键**：三层必须共享**同一个衰减时间常数**。
> 「语音情绪持续 3 秒而表情 0.2 秒就消失」是 AI 伴侣"假"的隐藏元凶之一。

### 1.8 验收方法（必须按这个来，别用"感觉好点了"）

- **样本量**：要把"60% vs 40% 偏好"检出到 p<0.05（power 0.8），约需 **150–200 次独立判断** ≈ 10–15 位听者 × 15 对。
  **只找 5 个人听 5 对，任何结论都在噪声里。**
- **盲听**：随机顺序 A/B，问"哪一段更像真人在说话"；用**符号检验**判断显著性。
- **客观门禁**：SIM 不得下降 >0.02；WER 不得上升 >1%。
- **客观指标**：WER/CER、SIM（wavlm-base-plus-sv 余弦）、情绪相似度（emotion2vec）、UTMOS、F0 RMSE、停顿位置 F1、副语言事件 F1。
- **自动回归**：[EmergentTTS-Eval](https://proceedings.neurips.cc/paper_files/paper/2025/hash/04970a25af46918606ba2cf0a3d7905d-Abstract-Datasets_and_Benchmarks_Track.html) **[核]** 做每次提交的门禁，人工盲听只做终检。
- **第 2 档要三盲**：听者不知道哪段是真人、哪段是哪个版本，**真人对照片段必须混入**（唯一绝对锚点）。

**UWB 第一坑**：天线延迟不校准会有 **0.5–1 m 系统性偏差**，必须用已知 1.0 m 标定 + 卡尔曼滤波。
**Apple U1/U2 不能用作自研定位源**：U2 的方向数据在第三方配件上不可用（[Apple 开发者论坛](https://developer.apple.com/forums/thread/802948) **[核]**）。

**→ 把"微电波"定位为「室内粗定位 + 跟随 + 防丢 + 存在感知」，绝不要指望它做精准动捕。**

### 3.2 表情头：自由度与"最少几路"

> **最优路径不是"堆 20 路舵机"，而是「6–8 路做出可识别表情 + 一块 1.28"~2.1" 圆屏做眼球」。**

| 区域 | DOF | 表情贡献 | 最少配置 |
| --- | --- | --- | --- |
| 眉毛 | 左右各 1 | **最高**（惊讶/愤怒/困惑） | 2 |
| 上眼睑 | 左右各 1 | **高**（眨眼、惊讶、困倦） | 2 |
| 嘴角 | 左右各 1 | **高**（微笑/难过） | 2 |
| **下颌开合** | 1 | **必需**（说话） | 1 |
| 眼球 | 2 | 中 | **0（用圆屏代替）** |
| 颈部 | 2 | 中（点头/摇头） | 可选 |

**→ 最少 7 路（2眉+2睑+2嘴角+1下颌）= 6 种可识别基础表情；加 2 路颈部 = 9 路为实用下限。**
**不要一开始上 20+ 路**：硅胶被拉扯的形变会互相干扰，调参成本指数上升。

### 3.5 硅胶工艺（**全项目最容易翻车的一环，且不是电子问题**）

| 材料 | 硬度 | 特点 | 用途 |
| --- | --- | --- | --- |
| Smooth-On **Ecoflex 00-30** | 00-30 | 最像真人皮肤，但**极易撕裂、易出油** | 眼周 |
| Smooth-On **Dragon Skin 10/20/30** | 10A–30A | **抗撕裂强** | **首选**：面部 10、受力区 20/30 |
| **国产铂金人体硅胶** | 0–10 度可定制 | **成本只有进口 1/3–1/5** | ✅ **第一次做先用这个练手** |

**关键参数**
- **硬度分区**：全脸统一硬度是新手常见错误。眼周 00-30，下颌/嘴角 10A。
- **厚度 1.5–3 mm**：<1mm 易撕裂且透骨架；>4mm 舵机拉不动。
- **皮下着色**：模具内壁先刷 1–2 层带色硅胶（血管色打底）再灌本色。**表面喷色必然开裂。**
- **发泡硅胶**：只用于脸颊局部；**不要整脸填充**（会吸水发霉）。

**失败模式**
| 症状 | 根因 | 修复 |
| --- | --- | --- |
| 气泡/针孔 | 未真空脱泡；灌注过快 | 抽至 −0.09MPa 保持 3–5min；沿模壁慢灌 |
| 撕裂 | 硬度太低/太薄/脱模暴力 | 加厚到 2.5mm；改 Dragon Skin 10 |
| **发粘不固化** | **铂金中毒**：接触硫/磷/锡/乳胶/树脂残留 | 母模彻底固化洗净；用**丁腈**手套 |
| 出油 | 配比失衡/过期 | 换材料；乙醇擦洗后封面 |

**成本（第一次做头，含失败冗余）**：硅胶 ¥400–900 + 模具硅胶 ¥120–200 + 外模 ¥80–150 + 脱模剂色浆 ¥150–300 + SLA 母模 ¥150–400 + **真空脱泡机 ¥400–900** + 器具 ¥150 = **约 ¥1450–3000**。
⚠ **预算必须留 2–3 倍材料冗余（第一次做必废）。**

### 3.6 口型同步（现实取舍）

> **做"下颌开合"，不要做"独立嘴唇闭合"。**
> 后者需 4+ 路舵机且硅胶互相牵扯，形变不可控、视觉收益低。

```
TTS 音频 →（有音素就做 viseme 映射；没有就退化为 RMS 包络）
        → 目标开口角度（0–25°）
        → [50Hz 控制环] 舵机位置（限速 + 限加速度，避免机械噪音）
```
- **建议先用"纯振幅包络"打通**（对每个 20ms 帧算 RMS + 低通），成本几乎为零，效果尚可。
- **关键细节**：舵机必须在音频**前 20–40ms** 开始动（硅胶有弹性延迟），用常量提前量补偿。
- 中文 6–8 个 viseme 就够（闭、开、圆、扁、齿、浊）。

### 3.7 安全（**这一节请务必让电子同学读**）

| 风险 | 机制 | 对策 |
| --- | --- | --- |
| **舵机堵转起火** | 廉价 PWM 舵机无过流保护，堵转时持续大电流，线材/驱动板可能熔毁 | **每路加自恢复保险丝（PTC）或 eFuse**；总线处 5A 保险丝 + 反接保护；**绝不用手机充电器直连 8 路舵机** |
| 峰值电流 | 8×ST3215 峰值 3A/路 → **峰值 24A** | **7.4V 10Ah 2S 锂电 或 7.5V 20A 开关电源**；星形接地；线径 ≥18AWG |
| 硅胶遇热 | 铂金硅胶长期 >80°C 加速老化 | 舵机与硅胶间留 5mm 空气层或铝箔隔热 |
| 长期接触皮肤 | 硅胶本身惰性，**色浆与脱模剂残留**是风险源 | 只用医疗/食品级材料；中性洗涤剂清洗 + 通风 72h；**不让儿童啃咬** |
| 机械伤害 | 机械臂/舵机突然动作 | 低速起步 + 急停按钮 + 软件力矩限制 + 硬限位 |

## 四、记忆架构（服务方向 7 的"同步记忆"部分）

> **完整报告（约 1.1 万字 + DDL/API 代码）：[`04b-调研-记忆架构.md`](04b-调研-记忆架构.md)**
> 本节只留"结论 + 对现有代码的评审"。

### 4.1 十二条结论（摘要）

1. **不要引入 Mem0 / Zep / Letta 作为运行时**——抄架构模式，不抄部署。
2. **统一抽象是「事件日志 + 物化视图」**，不是"一个大 JSON"。
3. 冲突解决用 **LWW-per-field + HLC（混合逻辑时钟）+ append-only 事件日志**；
   **不要上 Automerge / Yjs / cr-sqlite**（那是协同富文本的形状，10K ops 占 8–12MB 堆）。
4. **隐私是第一等公民**：记忆从写入那一刻就带 `privacy` 标签（五级），同步层**默认拒绝**未标注记忆出设备。
5. **合规重大利好**：《个人信息保护法》**第七十二条**「自然人因个人或者家庭事务处理个人信息的，不适用本法」
   → **自用/家用的桌宠目前不在 PIPL 管辖内**；一旦开放给陌生人使用（哪怕免费），第 28/29/38/39 条立刻生效。
6. **嵌入模型三档**：端侧 `EmbeddingGemma`（308M，768→128 维 MRL，量化 <200MB RAM）；自建 `bge-m3`（569M，1024 维，8192 token，dense+sparse+ColBERT）；质量档 `Conan-embedding-v2`（1.4B，MTEB 中文 74.24）。
7. **向量永不同步，只同步文本，各端本地重算**（维度不可混用）。
8. **服务端零知识加密 与 服务端向量检索本质冲突** → **服务端只做加密盲存储 + 转发，检索全在端上**。
   一年几千条 ≈ 几 MB，端侧全量暴力检索完全够用。
9. **事件总线用 MQTT 语义 + 自研 WebSocket hub**，topic `pet/{pet_id}/{domain}/{entity}/{action}`，**8 个 domain 闭合词表**：`sense|context|affect|memory|act|ctrl|env|sys`。
10. **落地必须分三步**，第一步（文件夹 + 单文件记忆库 + 手动导出导入）就该跑通"桌面 ↔ 手机记忆互通"。
11. **最大风险不是同步，是记忆污染**（幻觉写进长期记忆会自我强化）→ 两阶段写入 + `source_event_ids`。
12. **反模式**：整段对话塞进长期记忆 / 让 LLM 覆盖人格文件 / 无上限 append 向量 / 多设备各跑一份人格摘要再互相同步。

### 4.2 事件模型的两个亮点设计

```jsonc
PetEvent{
  event_id(ULID), hlc, ts_utc, ts_local, source, device_id, pet_id,
  type, actor, subject, payload,
  salience,        // ★ 一个字段驱动三件事：记忆写入阈值 / 是否打断用户 / 是否广播全设备
  valence, privacy,        // privacy: local|device|lan|sync|public（默认 local）
  ttl_ms,          // ★ 关键设计：发"30 分钟后自动失效的 study=true"，而不是显式发"不写作业了"
  trace_id, causation_id, schema_ver
}
```
- **`ttl_ms`**：缺失即失效，**消掉一大类状态同步 bug**。
- **"不打扰"必须是显式 `ctrl` 事件**（`pet/{id}/ctrl/arm.suppress`），不是各设备自己猜状态——
  这样可审计，且**新设备订阅 `ctrl/#` 自动继承礼貌规则**。
