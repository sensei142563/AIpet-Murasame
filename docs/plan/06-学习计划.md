# 学习计划（双人版）

> 面向：**你**（山东大学 · 计算机科学与技术）与**同学**（杭电 · 电子信息工程/技术）。
> 原则：**只学"下一步要用到的东西"**，不要系统性囤课。每项都给"最小可用学习量"和"验证学会了的小项目"。
> **本文件不含时间表**（与 `00` 一致）：只写"学到什么程度算够"。

---

## 0. 总原则：以项目驱动学习，别先修课

- **不要**先花半年"打基础"再开始做。你的项目本身就是最好的教材。
- 每学一个东西，必须在**当次的代码/板子上用掉一次**，否则不算学会。
- 判断"学会了"的标准：**能不看教程从零复现一次**，并且能解释**为什么这么设计**。
- 建议分配：做事 60% / 查资料与学习 30% / 写文档 10%。（文档不要省。）

### 2.3 舵机与运动

- **PWM 舵机**：脉宽与角度的关系、死区、堵转电流、供电电压对扭矩的影响。
- **串行总线舵机**（如 Feetech STS / Dynamixel XL330）：多路级联、读回角度与负载、位置模式/速度模式。
- **验证项目**：做一条"舵机走正弦/三角波并实时打印角度与电流"的实验——这是后续所有动作的基础。
- **必学安全**：软件限位 + 电流采样 + 独立电源 + 保险丝。**舵机不要从开发板 5V 取电。**

### 2.4 结构（表情头与机械臂的共同基础）

- 3D 打印基础（FDM 参数：层高/壁厚/填充/支撑/公差；什么时候用光敏树脂）。
- 舵机支架与连杆设计（四连杆驱动眼睑/嘴角是常见做法）。
- 快速原型：先**纸板 + 热熔胶**做机构验证，再画 3D 件。**不要一上来就画复杂结构。**

### 2.5 硅胶工艺（方向 3 的核心难点）

- 硅胶类型：铂金硫化（Platinum Cure）vs 锡固化（Tin Cure）；皮肤常见邵氏硬度 00-30 ~ 10A。
- 模具：3D 打印母模 + 硅胶翻模；脱模剂；分模线设计；抽真空/真空脱泡（气泡是失败首因）。
- 上色：皮下着色（内层染色 + 外层半透明）才能"像皮肤"；色浆比例与批次一致性。
- 常见失败：气泡、撕裂、发粘（配比不准/搅拌不均）、出油、边缘不贴合。
- **验证项目**：先做一块 5cm×5cm、2mm 厚的试样，练"配比—脱泡—固化—上色"全流程。成本几十元。
- **红线**：不以真人相貌为蓝本（见 `08-风险与合规.md`）。

### 2.6 与你（软件侧）的接口

- 他要能读懂并产出 ADR-000 的 `hw` JSON。
- 他要能在**没有实物**时用"假驱动"跑通逻辑（仿真优先，P3 原则）。
- 他需要的最小学数学：角度↔脉宽、扭矩↔力臂、电流↔功率、串口波特率↔传输时间。

## 4. 学习顺序（**按方法层，不按周**）

> 没有课表。下面按 `00` §3 的方法层排"学到什么程度就够用"。
> **原则**：只学到"下一步要用"的程度，用项目里的活当练习（`02-方法库.md` §6）。

| 对应层 | 你要学的 | 到什么程度够用 | 拿项目里的什么当练习 |
| --- | --- | --- | --- |
| **L0 地基** | Git（分支/合并/回滚/`reflog`）、pytest、Port/Adapter 分层 | 敢开分支乱改，能救回来 | 给动作曲线求值 / act 解析写 5 个单测 |
| **L1 记忆** | SQLite / Room、embedding 与余弦、BM25、RRF、FastAPI | 能写出一个能跑的记忆服务（哪怕只有 pull/push） | 把桌面的 `state.json`/`habits.json` 迁进 SQLite |
| **L2 手机** | Kotlin + Compose、ViewModel、Room、前台 Service、协程 | 能独立写一个新页面 + 接一个数据表 | 在 `chatter` 里加一个"记忆导出/导入"页 |
| **L2 渲染** | Live2D 的模型结构（`moc3`/`model3.json`/参数）、Cubism SDK 接入 | 能让**一个参数**被代码驱动；能解释 act 标签怎么解析 | 自己写一个最小的 act 状态机 |
| **L3 感知** | OpenCV 基础、相机内参、检测框/NMS、MediaPipe、MQTT | 能在手机上跑通姿态识别并输出数字 | 做一个"检测到在写作业"的端侧分类器 |
| **L2/L3 AR** | Unity AR Foundation 或 three.js + `@pixiv/three-vrm` + WebXR | 能在 AR 里放一个 VRM 并播一个动画 | 手机对着桌子，她站在上面会点头 |
| **L4 实体** | 功耗预算、BLE/MQTT 通信、锂电池基础、简单 PCB 常识 | **能算清"这样能撑多久"** | 写一张功耗预算表（`05` §5.4） |
| **L5 现实** | Home Assistant + ESPHome + MQTT；ROS2 基础（以后） | 能用 HTTP/MQTT 让一个灯亮 | "好冷 → 开暖风" |

**学到什么程度可以停**：能独立完成对应层的验收项（`00` §3）就够了，不必学完再动手。

**明确不用学（现在）**：从零训练大模型、CUDA 底层优化、编译原理、分布式共识的严格证明。
这些对当前阶段没有边际收益。
